# Alien Invasion

## About the Game
Alien Invasion is a space shooter game developed with Python and Pygame.

The player controls a spaceship and shoots bullets.

## Controls
- Right Arrow: Move right
- Left Arrow: Move left
- Space: Shoot
- Q: Quit the game

## Technologies
- Python 3.10+
- Pygame
- GitHub

## How to Install
Install Pygame:

```bash
pip install pygame
```

## How to Run
```bash
python alien_invasion.py
```
